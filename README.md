# Proyecto Discapacidad UCSC

Un proyecto web enfocado en la accesibilidad y discapacidad desarrollado para la Universidad Católica de la Santísima Concepción (UCSC).

## 📋 Descripción

Este proyecto tiene como objetivo proporcionar información y recursos relacionados con la discapacidad y accesibilidad, utilizando tecnologías web modernas para crear una experiencia inclusiva y accesible para todos los usuarios.

## 🛠️ Tecnologías Utilizadas

- **HTML** (72.1%) - Estructura y contenido
- **JavaScript** (19%) - Interactividad y funcionalidad
- **CSS** (8.9%) - Diseño y estilos

## 🚀 Características

- Interfaz web responsive
- Diseño enfocado en accesibilidad
- Contenido informativo sobre discapacidad
- Compatible con tecnologías de asistencia
